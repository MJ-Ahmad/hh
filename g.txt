====================================================================
BRANCH PURPOSES
====================================================================

main

Production-ready branch.
Stable code only.

--------------------------------------------------

dev

Primary development branch.
Daily coding work.

--------------------------------------------------

workspace

Temporary experimentation.
Testing ideas.

--------------------------------------------------

backup

Emergency backup snapshots.

--------------------------------------------------

archive

Historical preservation.

Never modify old archived states.

--------------------------------------------------

muster

Review area before merge.

--------------------------------------------------

junk

Disposable workspace.

Local temporary changes.

====================================================================
LONG-TERM PERSONAL RULES
====================================================================

Never push blindly.

Always check:

pwd

git branch --show-current

git remote -v

Always pull before starting work.

Always commit before switching context.

Keep main branch clean.

Use dev for development.

Use workspace for experiments.

Use backup for safety snapshots.

Use archive for historical preservation.

Create tags for major releases.

Keep commit messages meaningful.
